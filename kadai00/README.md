## ⑥難しかった点・次回トライしたいこと（又は機能）
- （難しい）HTMLはWebページの骨組みをつくるものとして比較的理解しやすかった一方で、CSSの指定が本当に難しかった…。
    - 「この部分の、この箇所だけを変えたい！」と思って指定したつもりでも変化がない…を繰り返しました。
    - AIに質問も繰り返し、そのたびにCSS上でメモを取るものの忘れてしまう…また覚え直す、でした。
- （次回トライ）今回は細かなデザインの調整やフォントなどまだまだこだわりきれていない部分も多いため、次回は「こんなこともできるのかな？」と自分で調べたりもしながら少しずつ表現の幅を広げていきたい。
